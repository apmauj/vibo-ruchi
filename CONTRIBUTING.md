# Contributing

Gracias por querer contribuir a `vibo-ruchi` — Snake de Sílabas.

Guía rápida
- Haz fork del repo y crea una rama descriptiva `feat/descripcion` o `fix/descripcion`.
- Mantén commits pequeños y descriptivos.
- Abre PR hacia `main` con descripción y screenshots si aplica.

Estilo de código
- JavaScript: estilo simple, evita frameworks cuando sea innecesario.
- CSS: seguir la convención existente en `public/game/assets/css/style.css`.

Testing
- No hay suite de tests automatizada todavía. Añade pruebas y documentación si introduces lógica compleja.

Releases
- Usaremos `main` como rama por defecto. Añade CHANGELOG en PR si el cambio es relevante.

Licencia
- Al contribuir aceptas que tu contribución se licencia bajo MIT (ver `LICENSE`).
